HTML Basics

كورس HTML Basics هو نقطة البداية لتعلّم بناء صفحات الويب، وفيه تتعرف على كيف تتكوّن الصفحة وتكتب هيكلها الأساسي، وتستخدم العناصر الشائعة مثل العناوين والفقرات والروابط والصور والقوائم والجداول. كمان تتعلم النماذج (Forms) لجمع بيانات المستخدم، والعناصر الدلالية (Semantic HTML) اللي تنظّم المحتوى وتحسّن الوصول وظهور الموقع في محركات البحث. بنهاية الكورس بتقدر تبني صفحة ويب كاملة وبسيطة من الصفر، وتكون جاهزة تنتقلي لـ CSS.

CSS Foundation

كورس CSS Foundations هو الخطوة اللي بعد HTML، وفيه تتعلمي كيف تتحكمي بشكل الصفحة وتنسقيها. بتتعرفي على كتابة القواعد (Selectors وProperties وValues)، وطرق ربط CSS بالصفحة، وكيف يتعامل المتصفح مع التعارض بين القواعد من خلال الـ Cascade والـ Specificity والـ Inheritance. كمان بتتعلمي الألوان والخطوط والوحدات وصندوق العناصر (Box Model)، وبنهاية الكورس بتقدري تنسقي صفحة HTML بشكل منظم ومرتب.
